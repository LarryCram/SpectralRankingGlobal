# Windows LaTeX & Zotero Setup Guide

> **To the Gemini Assistant on Windows:**
> This repository clone is configured **EXCLUSIVELY for LaTeX document authoring, bibliography management, and paper compilation**.
>
> ⛔ **DO NOT** attempt to install or run the Python data processing pipelines (`pipeline/`, `analysis/`, `enclaves/`, `build_flat_works.py`, DuckDB scripts, etc.). Those require hundreds of gigabytes of raw OpenAlex snapshot data and run exclusively on the Linux research workstation. All figures, tables, and analytical summaries needed for publication are pre-rendered and already committed to this repository.

## 1. Architecture & File Layout

All manuscript source files live under the `latex/` directory:

```text
SpectralRankingGlobal/
├── .gitignore
├── WINDOWS_LATEX_SETUP.md          <-- This guide
└── latex/
    ├── spbasic.bst                 <-- Shared Springer BibTeX style (TRACKED in Git)
    ├── MyLibrary.bib               <-- Master bibliography from Zotero (GITIGNORED!)
    │
    ├── NewERA/                     <-- Primary Active Manuscript (National Research Assessment)
    │   ├── main.tex                <-- Root document
    │   ├── references.bib          <-- Paper-specific citations (TRACKED in Git)
    │   ├── sections/               <-- Modular sections (01_introduction.tex .. 05_discussion.tex)
    │   ├── tables/                 <-- Pre-rendered LaTeX tables (tab1..tab4, TRACKED in Git)
    │   └── figures/                <-- Vector PDF figures (fig2..fig5, TRACKED in Git)
    │
    ├── enclaves/                   <-- Secondary Manuscript (Citation Enclaves)
    │   ├── main.tex
    │   └── sections/
    │
    └── PrestigeEsteem/             <-- Third Manuscript Outline
        ├── main.tex
        └── sections/
```

### Critical Path Resolution Rule
Each paper's `main.tex` expects compilation to be run with the **paper subdirectory as the working directory** (e.g., `latex/NewERA/`).
Notice the relative paths declared in `main.tex`:
- `\bibliographystyle{../spbasic}` — resolves up one directory to `latex/spbasic.bst`.
- `\bibliography{references,../MyLibrary}` (or `\bibliography{../MyLibrary}`) — resolves `references` to the local `references.bib` and `../MyLibrary` to `latex/MyLibrary.bib`.

## 2. The Missing `MyLibrary.bib` Gotcha

When this repo is first cloned onto Windows, **`latex/MyLibrary.bib` will not exist**.
This is intentional: `**/MyLibrary.bib` is listed in `.gitignore` because it is an 8.5+ MB live export generated dynamically by Zotero.

### How to obtain it:
You have two options (both are valid):

1. **Option A (Instant Bootstrap via copy)**:
   Copy `MyLibrary.bib` directly from the Linux workstation (`/home/lc/Projects_Antigravity/SpectralRankingGlobal/latex/MyLibrary.bib`) into `<repo_root>\latex\MyLibrary.bib` via network share, Dropbox, USB drive, or SCP/SFTP. This immediately unblocks compilation.

2. **Option B (Zotero Live Sync — Recommended for authoring)**:
   Configure Zotero with Better BibTeX to automatically export and keep `latex/MyLibrary.bib` up to date (see Section 3).

## 3. Zotero & Better BibTeX Setup on Windows

The manuscripts cite shared literature using citation keys generated by Zotero and the **Better BibTeX (BBT)** plugin (e.g. `docampoEvaluatingResearchPerformance2012`, `aagaardResearchFundingNational2016`, `hicks2015leiden`).

### Step 3.1: Install Zotero
- Download and install Zotero for Windows from [zotero.org](https://www.zotero.org/).
- Sign in to the user's Zotero account to synchronize the library.

### Step 3.2: Install the Better BibTeX (BBT) Plugin
1. Download the latest `.xpi` release from [retorque.re/zotero-better-bibtex/installation](https://retorque.re/zotero-better-bibtex/installation/).
2. In Zotero, go to **Tools** > **Add-ons**.
3. Click the gear icon (⚙️) in the top-right and select **Install Add-on From File...**.
4. Select the downloaded `.xpi` file and click **Install**.
5. Restart Zotero when prompted.

### Step 3.3: Set Up Continuous Auto-Export ("Keep Updated")
This ensures that whenever a reference is added or modified in Zotero, the `.bib` file in this repository is updated automatically:

1. In the left panel of Zotero, right-click **My Library** (or the project collection).
2. Select **Export Library...** (or **Export Collection...**).
3. Set **Format**: **`Better BibTeX`** (do NOT choose plain BibTeX).
4. Check the box: **`Keep updated`** (Automatic background synchronization).
5. (Optional) Check *Export Notes* or *Export Files* only if needed, but keeping them off keeps the `.bib` clean.
6. Click **OK**.
7. Browse to this repository on your Windows drive and select:
   `<repo_root>\latex\MyLibrary.bib`
8. Save.

BBT will now keep `latex/MyLibrary.bib` continuously updated in the background.

## 4. Windows LaTeX Distribution Setup

A complete TeX engine capable of `pdflatex` and `bibtex` is required.

### Recommended: MiKTeX
[MiKTeX](https://miktex.org/download) is recommended on Windows because of its automatic package management.
- During installation, set **"Install missing packages on the fly"** to **`Yes`** (not "Ask me first").
- Ensure the MiKTeX `bin` directory is added to your system `PATH` (default during setup).

### Packages Used by the Manuscripts
The documents use standard packages:
- `booktabs`, `tabularx`, `makecell` (advanced tables)
- `natbib` (author-year citation management with `\citep` and `\citet`)
- `amsmath`, `amssymb`, `mathrsfs` (equations and math symbols)
- `geometry` (margins)
- `caption`, `subcaption` (figure and table captions)
- `authblk` (author and affiliation formatting)
- `tikz` with libraries `positioning`, `arrows.meta`, `calc` (vector diagrams)
- `hyperref` (hyperlinks and PDF metadata)
- `graphicx` (PDF figure embedding)

If using **TeX Live**, install the `scheme-full` or ensure the above packages are installed via `tlmgr`.

### Verify in PowerShell / Command Prompt
```powershell
pdflatex --version
bibtex --version
```
Both commands must run without errors and show their respective version strings.

## 6. How to Compile Manuscripts

### Method 1: Via Terminal (PowerShell or Command Prompt)
Always `cd` into the manuscript's directory before compiling:

```powershell
# Compile NewERA paper
cd latex\NewERA
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

This generates `latex\NewERA\main.pdf` (15 pages).

### Method 2: Via LaTeX Workshop in the IDE
1. Open `latex/NewERA/main.tex` in the editor.
2. Press **`Ctrl + Alt + B`** (or click the green Play button in the top right / LaTeX Workshop side panel > **Build LaTeX project**).
3. To view the compiled document side-by-side:
   - Press **`Ctrl + Alt + V`** (or click the "View LaTeX PDF" icon in the top right).
   - Select **View in VS Code tab**.
4. SyncTeX works both ways: `Ctrl + Click` in the PDF navigates to the corresponding `.tex` source line, and `Ctrl + Alt + J` in `.tex` jumps to that position in the PDF.

## 7. Working Rules & Git Hygiene

When working on LaTeX on Windows, adhere strictly to these rules:

1. **Where to add new citations**:
   - If a citation is a permanent addition to the author's Zotero library, add it in **Zotero**. Better BibTeX will auto-update `latex/MyLibrary.bib`.
   - If a citation is paper-specific or temporary, add it to `latex/NewERA/references.bib` (which is tracked in Git).
2. **Never Git Commit Build Artifacts**:
   - Files with extensions `.aux`, `.bbl`, `.blg`, `.log`, `.out`, `.synctex.gz`, and generated `main.pdf` are gitignored. Do NOT force-add them (`git add -f`).
3. **Never Un-ignore `latex/MyLibrary.bib`**:
   - Keep `latex/MyLibrary.bib` untracked. This avoids committing multi-megabyte binary-like text diffs to Git and prevents merge conflicts across machines.
4. **Never Modify `latex/NewERA/figures/*.pdf` without reason**:
   - These are pre-rendered vector graphics produced by Python data scripts on the Linux machine. They are committed to Git so you don't need Python or the raw data on Windows.
5. **Editing Text and Tables**:
   - Text edits go into the modular files in `latex/NewERA/sections/`.
   - Table edits can be made directly in `latex/NewERA/tables/` if fine-tuning captions or alignments.
